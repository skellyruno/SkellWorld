# Skellenese | the language of the Skelly world

**Status:** cultural foundation / draft, not a published official dictionary.

Skellenese (Skell-uh-neez, two Ls) is Skelly's fictional creative language:
shared expressions, skeleton slang, lore, music tags, audience participation
and story elements for New Era, The Graveyard, Song Wars and the SkellWorld
community. It is deliberately **not** the SkellLang programming language.

## Three related identities
- **Skellenese** - community vocabulary, lyrical phrases, lore and spoken lingo.
- **SkellCipher** - a visual script, puzzle alphabet and easter-egg system.
- **SkellLang** - a separate developer language with .skell source files.
  Keep its compiler grammar and plugin IDs unchanged.

## What is versioned here
- dictionary.json: suggested terms and origins; all current entries are
  unapproved creative examples, not claims of the artist's established lingo.
- skellcipher.json: design specifications without committing to a final glyph set.
  Never label an unfinished alphabet as working.
- SkellWorld/tests/test_skellenese.py: validates schema, terminology, statuses
  and ownership/credit metadata without adding runtime or network code.

## First editorial workflow
1. Collect the actual existing skeleton lingo, with examples from the artist.
2. Approve or reject draft terms; document spelling, definition, pronunciation,
   owner/creator attribution, usage examples and moderation/rights.
3. Create several *original* visual alphabet directions, then approve only
   one canonical SkellCipher glyph geometry per character.
4. Add a readable plaintext version to all visual cipher puzzles.
5. Pilot with one opt-in Discord word reveal or short music easter egg.
6. Audit any user-submitted material for consent and IP before commercial use.

This draft is not a substitute for encryption or authentication. Do not put
passwords, payments, private messages or security claims into SkellCipher.
Nothing in this culture folder is loaded by the localhost SW1 plugin bus.
